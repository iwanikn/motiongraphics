# Motion Graphics Engine

Tahap 1-3: engine animasi `s`, pemutar canvas 9:16 (720x1280), ekspor MP4 (WebCodecs, tanpa suara), dan alur tempel JSON ide, narasi, animasi.

Buka `index.html` di browser, tempel kode scene, klik **Muat scene**.

Roadmap: suara Gemini TTS dan penanda scene, SFX dan musik, auth dan kredit.
