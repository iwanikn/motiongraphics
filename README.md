# Motion Graphics Engine

Tahap 1-4: engine animasi `s`, pemutar canvas 9:16, ekspor MP4 (WebCodecs), alur tempel JSON ide, narasi, animasi, dan suara (Gemini TTS atau upload audio, batas scene otomatis).

Buka `index.html` di browser, tempel kode scene, klik **Muat scene**.

Roadmap: efek suara (sfx), subtitle, musik latar, auth dan kredit. Catatan: tombol Generate suara hanya jalan bila halaman dibuka di luar claude.ai (mis. GitHub Pages).
