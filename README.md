# Motion Graphics Engine

Tahap 1-5: engine animasi `s`, pemutar canvas 9:16, ekspor MP4 (WebCodecs), alur tempel JSON ide, narasi, animasi, suara (Gemini TTS atau upload audio), efek suara sintetis, subtitle, dan musik latar.

Buka `index.html` di browser, tempel kode scene, klik **Muat scene**.

Roadmap: auth, proyek tersimpan, kredit dan pembayaran. Catatan: tombol Generate suara hanya jalan bila halaman dibuka di luar claude.ai (mis. GitHub Pages).
